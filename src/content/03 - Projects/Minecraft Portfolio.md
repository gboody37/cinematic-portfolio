# ⛏️ Minecraft Portfolio

> **Tech Stack**: Next.js | React | CSS

---

## 📌 Application Summary
A Minecraft-themed web portfolio that integrates directly with this Obsidian AI Brain. It features a hotbar navigation system, a chest UI for displaying projects (pulled dynamically from the `03 - Projects` directory), and an Enchantment Table for skills.

---

## 🛠️ Key Features
- **Dynamic Content**: Uses Node.js `fs` and `gray-matter` to read Markdown files from the Obsidian vault and render them as items.
- **Minecraft UI**: Pixel-art fonts, inset CSS shadows, XP bars, and hotbar navigation (keys 1-9).
- **Chest Inventory**: Projects are loaded as items in a chest grid. Hovering shows their status and tags.
- **Enchantment Table**: Displays technical skills as enchantments with varying levels and lapis costs.
