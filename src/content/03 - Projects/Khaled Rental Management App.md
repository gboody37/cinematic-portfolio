# Khaled Rental Management App

![Rental App Dashboard](/photo/projects/rental-app.jpg)

A comprehensive **rental property management application** designed for landlords to track tenants, lease agreements, monthly payments, and property maintenance requests — all from a single dashboard.

## Core Features

### Tenant Portal
Tenants can view their lease details, submit maintenance requests, and make payments through a self-service portal. Automated reminders ensure rent is never late.

### Financial Tracking
Complete income and expense tracking with monthly profit/loss statements. Export reports to Excel for accounting purposes.

### Property Overview
Visual dashboard showing occupancy rates, upcoming lease expirations, and pending maintenance tasks across all properties.

## Tech Stack
- Next.js & React
- PostgreSQL Database
- JWT Authentication
- Responsive Mobile-First Design
